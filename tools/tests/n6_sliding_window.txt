# n6_sliding_window.txt -- N6 通关测试值：停等/GBN/SR 窗口与利用率
# 用法: powershell -ExecutionPolicy Bypass -File .\tools\check-n6.ps1
# 规则: a = RTT / Td ；W_need = 1 + a（能保持链路不停的最小窗口）
#       GBN 最大窗口 = 2^n - 1 ；SR 最大窗口 = 2^(n-1)
#       利用率 U = min(1, W / (1 + a))；停等式用 W = 1
#       窗口内第 k 个帧丢失：GBN 重发 (W - k + 1) 个（k 在窗口内），SR 只重发 1 个
# 期望值全部经手算 + 实测双向核对。
#
# MAIN: n=3, Td=1ms, RTT=4ms, 丢失第 1 帧
3 1 4 1 => seq_space_2n       = 8
3 1 4 1 => a_ratio_RTT_over_Td= 4.000000
3 1 4 1 => window_needed      = 5
3 1 4 1 => gbn_max_window     = 7
3 1 4 1 => sr_max_window      = 4
3 1 4 1 => util_stop_and_wait = 0.200000
3 1 4 1 => util_gbn           = 1.000000
3 1 4 1 => util_sr            = 0.800000
3 1 4 1 => resend_on_loss_gbn = 7
3 1 4 1 => resend_on_loss_sr  = 1
3 1 4 1 => note               = GBN is enough, SR window is too small
#
# B1 边界: n=2（GBN 容 3、SR 容 2，都不够 5 -> 链路会空闲），丢失第 4 帧（在 GBN 窗口之外）
2 1 4 4 => gbn_max_window     = 3
2 1 4 4 => sr_max_window      = 2
2 1 4 4 => util_gbn           = 0.600000
2 1 4 4 => util_sr            = 0.400000
2 1 4 4 => resend_on_loss_gbn = 0
2 1 4 4 => resend_on_loss_sr  = 1
2 1 4 4 => note               = neither window is big enough: the link idles
#
# B2 边界: n=4（序号空间 16，两个窗口都够 -> 都能跑满）；丢失窗口内最后一帧
4 1 4 15 => seq_space_2n       = 16
4 1 4 15 => gbn_max_window     = 15
4 1 4 15 => sr_max_window      = 8
4 1 4 15 => util_gbn           = 1.000000
4 1 4 15 => util_sr            = 1.000000
4 1 4 15 => resend_on_loss_gbn = 1
4 1 4 15 => note               = both GBN and SR can keep the link busy
#
# B3 边界: Td 远大于 RTT（a=0.5 -> 需要窗口 2），n=2 时只有 GBN 够
2 2 1 1 => a_ratio_RTT_over_Td= 0.500000
2 2 1 1 => window_needed      = 2
2 2 1 1 => gbn_max_window     = 3
2 2 1 1 => sr_max_window      = 2
2 2 1 1 => util_gbn           = 1.000000
2 2 1 1 => util_sr            = 1.000000
2 2 1 1 => note               = both GBN and SR can keep the link busy
