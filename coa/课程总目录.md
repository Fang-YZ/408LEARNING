## 1. 教学规则（学员约定版）

1. 每课先讲「概念 + 示例」（含手算演示与 C 观察实验），再布置作业；逐题批改（判定表 + 质量星级 + 点评）；**全部通过才解锁下一课**；未通过则指出要改哪里，重交后重批。
2. 每讲完一课自动整理 markdown 复习笔记（**30 秒速览 / 代码模板 / 坑清单 / 复习自查清单 / 作业清单**），并维护本总目录记录进度。
3. 维护《错题本.md》（本文件夹内）：每次批改自动登记错题，格式为 **来源 / 知识点 / 我的错误 / 正确写法 / 掌握勾选**。
4. 中文讲解；示例程序输出全用英文（避免 Windows 终端乱码），中文只出现在注释与笔记中。
5. 书写规范：计算题写完整步骤 + 单位；进制/补码题标注位长（8 位 / 32 位等）；C 实验沿用 C 课风格公约（4 空格缩进、花括号不省略、snake_case、`-Wall -Wextra` 零警告）。
6. 每课作业附「通关测试值」（**含边界值**，均为已知正确答案）：先手算/自测验证，再提交。
7. 学员可随时打断提问，结合本课上下文回答。
