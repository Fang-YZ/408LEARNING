## 一、30 秒速览

- **码元（symbol）**：承载数据的基本信号单位；**波特率** = 每秒码元数（Baud），**比特率** = 每秒比特数（b/s）。
- 两者关系：**比特率 = 波特率 × 每码元携带的比特数**，而每码元比特数 = **log₂V**（V 为码元的离散状态数）。
- **奈奎斯特定理（理想无噪声、带宽受限）**：`C = 2B·log₂V`（b/s）。它告诉你"**最多**能做到多少"，前提是信道无噪声。
- **香农定理（有噪声信道）**：`C = B·log₂(1 + S/N)`（b/s）。**没有 V**，只与带宽和信噪比有关。
- **分贝换算**：`S/N(dB) = 10·log₁₀(S/N)`，所以 20 dB → S/N = 100；30 dB → 1000；40 dB → 10000。
- **两个定理一起用时取较小的那个**：实际可达速率 ≤ min(奈奎斯特, 香农)。
- **编码**：曼彻斯特编码**自带同步且无直流分量**，但**波特率是比特率的 2 倍**（带宽开销翻倍）——10 Mb/s 传统以太网用它。
- **三种交换**：电路交换（先建连接、独占、时延稳定）｜报文交换（整报文存储转发）｜**分组交换（流水线，时延最短）**。
- **数据报 vs 虚电路**：数据报**无连接**、逐分组独立选路、可能乱序；虚电路**先建连接**、同一条路径、按序到达。
- **物理层不关心比特的含义**，只负责把比特"搬过去"；中继器/集线器是它的设备（**集线器不隔离冲突域**）。

## 二、本课知识点（完整版）

### 2.1 基本概念（考点密集，必须分清）

| 术语 | 含义 | 易错点 |
| --- | --- | --- |
| 信源 / 信宿 | 发送端 / 接收端 | 信源产生数据，信宿消费数据 |
| 信道 | 信号传输的通道 | 分**单工 / 半双工 / 全双工** |
| 信号 | 数据的电/光/电磁表示 | 分**数字信号 / 模拟信号** |
| 码元 symbol | 承载数据的基本波形单位 | 一个码元可携带**多个**比特 |
| 波特率 Baud | 每秒传输的**码元数** | 单位 Baud，与信号状态数**无关** |
| 比特率 b/s | 每秒传输的**比特数** | 与信号状态数**有关** |
| 带宽 | 信道能通过的频率范围（Hz） | 与"最高数据率"是两个视角 |
| 基带 / 宽带信号 | 原样传输数字信号 / 调制到高频载波 | 基带适合短距离局域网 |

> **一句话公式**：`比特率(b/s) = 波特率(Baud) × log₂V`

**换算示例（考点）**：某信道波特率 2000 Baud，采用 16 种码元状态：
每个码元 = log₂16 = 4 bit → 比特率 = 2000 × 4 = **8000 b/s**。

**通路的三种通信方式**：

| 方式 | 数据流向 | 例子 |
| --- | --- | --- |
| 单工 | 只能一个方向 | 广播、电视 |
| 半双工 | 双向但不能同时 | 对讲机 |
| 全双工 | 双向同时 | 电话、现代以太网 |

### 2.2 奈奎斯特定理（理想信道，无噪声）

```
C = 2 · B · log₂V      (b/s)
```
- `B`：信道带宽（Hz）；`V`：码元的离散状态数（电平数）。
- 含义：带宽受限、**无噪声**条件下，极限数据率就是它。
- 由它可反推：`log₂V = C / (2B)`，即码元状态数越高，同样的带宽能传更多比特（但抗噪能力下降）。

### 2.3 香农定理（有噪声信道）

```
C = B · log₂(1 + S/N)      (b/s)
```
- `S/N` 是**线性比值**（不是 dB！）；若给的是 dB，**必须先换算**。
- 定理含义：噪声存在时提高速率不能靠"加电平数"，只能靠**加带宽**或**提高信噪比**。
- 结论：香农容量与 `V` **无关**，这是与奈奎斯特最本质的区别。

**分贝 → 线性换算表（背下来省时间）**：

| 给定 SNR | S/N 线性值 | 备注 |
| --- | --- | --- |
| 0 dB | 1 | log₂(1+1) = 1 |
| 10 dB | 10 | |
| 20 dB | 100 | |
| 30 dB | 1000 | 约 2^9.97 |
| 40 dB | 10000 | 约 2^13.29 |
| 60 dB | 1000000 | 约 2^19.93 |

### 2.4 编码与调制

**① 数字数据 → 数字信号（编码）**：

| 编码 | 特点 | 考点 |
| --- | --- | --- |
| 归零码 RZ | 每个码元中间回到零电平 | 需要 3 种电平 |
| 不归零码 NRZ | 电平不回到零 | 长串相同比特时**无法同步** |
| 反向不归零码 NRZI | 电平**跳变**表示 1，不变表示 0 | |
| **曼彻斯特编码** | 每码元**中间跳变**：低→高=1 或 0/高→低 | **自带位同步**；**波特率 = 2 × 比特率** |
| **差分曼彻斯特编码** | 码元**开始处有无跳变**表示 0/1，中间跳变仅用于同步 | 抗干扰更强 |

> **必考数值**：传统以太网 10 Mb/s 用曼彻斯特编码 → **波特率 = 20 MBaud**（这正是"10Base-T 需要 20 MHz 带宽"的来源）。
> 100 Mb/s 以太网改用 **4B/5B + NRZI** 等方案，把开销从 2 倍降到 1.25 倍。

**② 数字数据 → 模拟信号（调制）**：

| 方式 | 改变的参数 | 备注 |
| --- | --- | --- |
| ASK 幅移键控 | 幅度 | 抗噪最差 |
| FSK 频移键控 | 频率 | 抗噪好，带宽开销大 |
| PSK 相移键控 | 相位 | 常用；2PSK 每种码元 1 bit |
| QAM 正交幅度调制 | 幅度+相位 | 状态多、速率高，如 16QAM 每码元 4 bit |

**③ 模拟数据 → 数字信号**：PCM（采样 → 量化 → 编码），采样频率须满足 `f ≥ 2·f_max`（采样定理）。

### 2.5 电路交换 / 报文交换 / 分组交换

| 维度 | 电路交换 | 报文交换 | 分组交换 |
| --- | --- | --- | --- |
| 是否先建连接 | **需要**（呼叫建立） | 不需要 | 不需要 |
| 资源占用 | **独占**整条通路 | 逐跳共享 | 逐跳共享 |
| 转发单位 | 比特流直通 | **整个报文** | **分组** |
| 时延 | 建立长 + 传输短，**稳定** | 存储转发，**时延大**（与跳数×报文长度成正比） | 存储转发 + **流水线**，**时延小** |
| 突发数据效率 | 低（空闲也占着） | 中 | **高** |
| 适用 | 实时语音（传统电话） | 早期电报 | **因特网** |

**时延计算骨架（本课示例已实现，可动手验证）**：设报文 L bit、每跳速率 R、跳数 k：

```
电路交换：T = 建立时间 + L / R                       （不存储转发）
报文交换：T = k · (L / R)                            （每跳都要收完整个报文）
分组交换：T = (k + p − 1) · (P / R)   , p = L / P     （p 个 P bit 的分组流水线）
```

> **分组快在哪**：第一个分组在第 2 跳被转发的同时，第二个分组正在第 1 跳传输 → **流水线并行**。
> 当 P = L（只有一个分组）时，分组交换退化成报文交换，**没有流水线收益**。

### 2.6 数据报与虚电路

| 维度 | 数据报（因特网 IP） | 虚电路（如 ATM、帧中继） |
| --- | --- | --- |
| 连接 | **无连接** | **面向连接**（有建立/拆除阶段） |
| 路径 | 每个分组**独立选路** | 所有分组走**同一条**逻辑通路 |
| 地址 | 每个分组带完整目的地址 | 分组带**虚电路号**（短） |
| 到达顺序 | 可能**乱序**、可能丢失 | **按序**到达 |
| 可靠性 | 由端系统（TCP）负责 | 由网络负责 |
| 路由器状态 | 无连接状态 | 需维护虚电路表 |

### 2.7 传输介质与物理层接口特性

| 介质 | 特点 |
| --- | --- |
| 双绞线（UTP/STP） | 便宜、易布线；**5 类/超 5 类**可支持 100 Mb/s ~ 1 Gb/s，100 m 限制 |
| 同轴电缆 | 抗干扰较好，早期以太网/有线电视 |
| 光纤 | **带宽极大、抗电磁干扰、损耗小、安全**；多模（便宜、短距）/ 单模（贵、长距） |
| 无线 | 无线电波 / 微波 / 红外；易受干扰、需共享介质 |

**物理层接口四大特性（简答高频）**：

| 特性 | 管什么 |
| --- | --- |
| 机械特性 | 接口的**形状、引脚数、排列**（接线器的物理规格） |
| 电气特性 | 电压范围、阻抗、传输速率 |
| 功能特性 | 某条线上出现的电平表示**什么含义** |
| 规程特性（过程特性） | 各信号线**动作的时序**关系 |

### 2.8 物理层设备（注意"层次边界"）

| 设备 | 作用 | 关键结论 |
| --- | --- | --- |
| 中继器 | 放大/整形信号，延长传输距离 | 只处理**物理层**；**不隔离冲突域** |
| 集线器 HUB | 多端口中继器，广播式转发 | 所有端口**同属一个冲突域**、同一广播域；**共享带宽**（10 Mb/s 分给 N 台） |

> **信号在传输中受损的三种形式**：**衰减**（幅度变小）、**延迟变形**（不同频率速度不同）、**噪声**（干扰）。

## 三、代码模板

### 3.1 信道容量计算器（奈奎斯特 + 香农）

`networks/N03_physical_layer/examples/channel_capacity.c`

```powershell
gcc -Wall -Wextra -O2 -o channel_capacity.exe channel_capacity.c -lm
.\channel_capacity.exe                 # 默认 B=3000 Hz, V=4, SNR=20 dB
.\channel_capacity.exe 3000 4 20       # 或自己给参数（SNR 给 -1 表示理想信道）
```

核心代码（可直接抄）：

```c
#include <math.h>
#define log2_of(x) (log(x) / log(2.0))          /* C 语言没有 log2 的标准老写法 */

double nyquist = 2.0 * B * log2_of(V);          /* 理想信道：C = 2B·log2(V)   */
double snr     = pow(10.0, snrdb / 10.0);       /* dB -> 线性比值             */
double shannon = B * log2_of(1.0 + snr);        /* 有噪信道：C = B·log2(1+S/N) */
double limit   = (nyquist < shannon) ? nyquist : shannon;   /* 取较小者 */
```

**实测输出（已知答案，可对拍）**：`B=3000, V=4, SNR=20 dB`

```
bits_per_symbol    = 2.000000 bit
nyquist_capacity   = 12000 bps
snr_linear         = 100.000000
shannon_capacity   = 19974.634448 bps
max_data_rate      = 12000.000000 bps
limit_source       = nyquist
```

## 四、坑清单

### 4.1 概念与计算陷阱（408 高频）

| # | 坑 | 正解 |
| --- | --- | --- |
| 1 | 把波特率和比特率当成一回事 | 比特率 = 波特率 × log₂V；只有 V=2 时才数值相等 |
| 2 | 给香农定理套上"电平数 V" | 香农公式里**没有 V**，只有 B 和 S/N |
| 3 | 给奈奎斯特定理套上信噪比 | 奈奎斯特假设**无噪声**，不涉及 S/N |
| 4 | 把 dB 当线性比值代进香农公式 | 20 dB **不是** 20，要先算 `10^(20/10) = 100` |
| 5 | 两个定理不会"一起用" | 有噪声且给了 V 时，实际速率 ≤ **min**(2B·log₂V, B·log₂(1+S/N)) |
| 6 | 认为曼彻斯特编码"更省带宽" | 恰恰相反：**波特率是比特率的 2 倍**，带宽开销翻倍，换来的是自带同步 |
| 7 | 说"分组交换一定比电路交换快" | 小数据量 + 建链快时电路交换可能更快（setup 是固定成本） |
| 8 | 把 P = L 的分组交换仍当"更优" | 只有一个分组时**退化成报文交换**，没有流水线收益 |
| 9 | 把"报文交换"算成 `L/R + 传播` | 报文交换是**每跳都收完整个报文**，所以是 `k·(L/R)`（忽略传播） |
| 10 | 认为虚电路"每个分组带完整目的地址" | 虚电路分组带的是**虚电路号**；完整地址是数据报的做法 |
| 11 | 认为集线器能隔离冲突域 | 集线器**所有端口同一冲突域**；交换机/网桥才能隔离冲突域 |
| 12 | 混淆物理层接口四大特性 | 机械=形状引脚｜电气=电压阻抗｜功能=电平含义｜规程=动作时序 |
| 13 | 把"采样定理"和"奈奎斯特定理"混为一谈 | 采样定理说 `f_s ≥ 2·f_max`（模拟转数字）；奈奎斯特定理算**信道容量** |
