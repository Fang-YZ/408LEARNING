## 一、30 秒速览

- **导向介质**（有线）：双绞线、同轴电缆、光纤；**非导向介质**（无线）：无线电波、微波、红外。
- **双绞线**：最便宜、最常用；**5 类/超 5 类** 100 m 内可跑 100 Mb/s ~ 1 Gb/s；**6 类**可到 10 Gb/s（55 m 内）。绞合的作用是**抵消电磁干扰**。
- **同轴电缆**：抗干扰优于双绞线，早期以太网（10Base-5/2）与有线电视用；现在基本被双绞线与光纤取代。
- **光纤**：**带宽极大、抗电磁干扰、损耗小、保密性好**；分**多模**（便宜、光源为 LED、距离短）与**单模**（贵、光源为激光、距离长）。
- **无线**：微波**直线传播**，需视距；红外**不能穿透障碍物**，只能短距视距。
- **物理层接口四大特性**：机械（形状/引脚数）、电气（电压/阻抗/速率）、功能（电平含义）、规程（动作时序）。
- **中继器**：放大整形信号、延长距离，**只处理物理层**，**不隔离冲突域**。
- **集线器**：多端口中继器，**所有端口共享带宽且同属一个冲突域、一个广播域**。
- **交换机**：每个端口**独占带宽**并**各自一个冲突域**（数据链路层设备，详见 N8）；**VLAN 才划广播域**。

## 二、本课知识点（完整版）

### 2.1 导向传输介质

#### ① 双绞线（Twisted Pair）

| 项目 | 内容 |
| --- | --- |
| 结构 | 两根绝缘铜线**绞合**在一起；分**屏蔽 STP**（有金属屏蔽层）与**无屏蔽 UTP** |
| 绞合的作用 | **抵消相邻线对间的电磁干扰与串扰**（考点：为什么必须绞合） |
| 分类 | 3 类（10 Mb/s）、**5 类 / 超 5 类**（100 Mb/s ~ 1 Gb/s）、**6 类**（10 Gb/s，≤55 m）、7 类 |
| 最大段长 | **100 m**（水平布线标准值，必背） |
| 接口 | **RJ-45** |
| 优点 | 便宜、易安装、易维护 |
| 缺点 | 抗干扰能力较弱、距离受限、易被窃听 |

#### ② 同轴电缆（Coaxial Cable）

| 项目 | 内容 |
| --- | --- |
| 结构 | 内导体（铜芯）→ 绝缘层 → 外导体（编织网屏蔽）→ 外护套 |
| 分类 | **基带**同轴（50 Ω，数字信号，早期以太网）/ **宽带**同轴（75 Ω，模拟信号，有线电视） |
| 优点 | 抗干扰较好、带宽比双绞线大 |
| 缺点 | 粗、硬、贵、布线不便；已被双绞线与光纤取代 |
| 历史 | 10Base-5（粗缆，500 m）、10Base-2（细缆，185 m） |

#### ③ 光纤（Optical Fiber）

| 项目 | 内容 |
| --- | --- |
| 原理 | **全反射**：光在纤芯（高折射率）与包层（低折射率）界面不断全反射向前传播 |
| 分类 | **多模光纤**：纤芯粗、光走多条路径、**LED** 光源、便宜、距离短（几百米~2 km）<br>**单模光纤**：纤芯细（约 8~10 μm）、光沿一条路径、**激光**光源、贵、距离长（几十 km） |
| 优点 | **带宽极大、抗电磁干扰与雷电、损耗小（中继距离长）、保密性好（不辐射）** |
| 缺点 | 贵、安装维护需专业设备、**易折断** |
| 接口/标准 | 1000Base-SX/LX、10GBase 系列 |

> **高频对比题**：光纤"抗电磁干扰"是因为**它传的是光，不是电**；"保密性好"是因为**光信号不向外辐射**，不易被搭线窃听。

### 2.2 非导向传输介质（无线）

| 介质 | 频段/特点 | 关键考点 |
| --- | --- | --- |
| 无线电波 | 频率较低、**可穿透建筑物**、全向传播 | 易受干扰；适合广播、移动通信 |
| 微波 | 频率高（GHz）、**直线传播** | **必须视距（LOS）**；地面微波需中继塔；卫星微波时延大 |
| 红外 | 频率很高、**不能穿透障碍物** | 只能**短距离、视距**、同一房间内使用（遥控器） |

### 2.3 物理层接口的四大特性（简答必背）

| 特性 | 管什么 | 举例 |
| --- | --- | --- |
| **机械特性** | 接口的**形状、尺寸、引脚数量与排列**（接线器的物理规格） | RJ-45 有 8 个引脚；USB 接口形状 |
| **电气特性** | 电压范围、阻抗、**传输速率**、信号电平的电气参数 | 用 -5 V ~ +5 V 表示 0/1 |
| **功能特性** | 某条线上出现的**电平表示什么含义** | 某引脚高电平=1、低电平=0；某引脚=时钟 |
| **规程特性**（过程特性） | 各信号线**动作的时序关系**（谁先谁后） | 建立连接时先发什么信号、再发什么信号 |

### 2.4 物理层设备

#### ① 中继器（Repeater）

- 作用：**放大并整形**衰减/失真的信号，从而**延长网络传输距离**。
- 层次：**只工作在物理层**，不理解帧、不理解比特的含义（只管把 0/1 波形变干净）。
- **不隔离冲突域**：中继器两端**属于同一个冲突域**（这也是"5-4-3 规则"存在的原因）。
- 与集线器的关系：**集线器本质就是多端口中继器**。

#### ② 集线器（Hub）

| 项目 | 内容 |
| --- | --- |
| 本质 | 多端口中继器（物理层设备，广播式转发） |
| 带宽 | **所有端口共享**总带宽：10 Mb/s 的 8 口集线器，平均每台只有 1.25 Mb/s |
| 冲突域 | **所有端口同属一个冲突域**（同时只能一台发送，否则冲突） |
| 广播域 | 所有端口**同属一个广播域** |
| 工作方式 | 收到信号后向**除输入端口外的所有端口**转发（泛洪） |

#### ③ 与交换机、路由器的层次对照（横向记忆）

| 设备 | 最高处理层次 | 隔离冲突域 | 隔离广播域 | 带宽 |
| --- | --- | --- | --- | --- |
| 中继器 / 集线器 | 物理层 | ❌ 否 | ❌ 否 | 共享 |
| 网桥 / 交换机 | 数据链路层 | ✅ 是 | ❌ 否（**VLAN 可以**） | 每端口独占 |
| 路由器 | 网络层 | ✅ 是 | ✅ 是 | 每端口独占 |

> 口决：**"集线器不隔离，交换机隔冲突，路由器隔广播，VLAN 切广播"**。

## 四、坑清单

| # | 坑 | 正解 |
| --- | --- | --- |
| 1 | 认为双绞线的绞合是为了"结实" | 绞合是为了**抵消电磁干扰与串扰** |
| 2 | 记错双绞线最大段长 | **100 m**（水平布线标准；6 类跑 10 G 时是 55 m） |
| 3 | 把光纤说成"抗干扰因为屏蔽层好" | 光纤传的是**光**，根本不受电磁干扰；**保密性好**是因为**不向外辐射** |
| 4 | 搞混单模/多模 | **单模**：细芯、激光、贵、**远**；**多模**：粗芯、LED、便宜、**近** |
| 5 | 认为红外穿透力强 | 红外**不能穿透障碍物**，只能视距短距 |
| 6 | 认为微波可以绕过障碍 | 微波**直线传播，必须视距** |
| 7 | 混淆四大特性 | 机械=形状引脚｜电气=电压阻抗速率｜功能=电平含义｜规程=动作时序 |
| 8 | 认为中继器能隔离冲突域 | 中继器/集线器**都在同一个冲突域**；只有网桥/交换机隔离冲突域 |
| 9 | 认为交换机隔离广播域 | 交换机**不隔离广播域**（默认一个大广播域），**VLAN 才能划分** |
| 10 | 集线器带宽算错 | 集线器是**共享**带宽：N 台平分；交换机是**每口独占** |
| 11 | 以为集线器能"看懂"帧 | 集线器只到**物理层**，看不懂 MAC 地址、不做过滤 |
| 12 | 把双绞线/同轴/光纤归为"非导向介质" | 这三者是**导向介质**；无线电波/微波/红外才是非导向 |
