## 一、30 秒速览

- 一句话定义：**自治**的计算机系统经**互连**（通信线路）并按**协议**协同 → 目的：**资源共享**与信息传递。
- 网络功能：**数据通信是基础，资源共享是核心目的**；还有分布式处理 / 并行计算 / 负载均衡 / 高可靠 / 易扩展。
- 分类别死记：按范围（PAN<LAN<MAN<WAN）、按使用者（公用 / 专用）、按拓扑（总线 / 星 / 环 / 网状）、按交换（电路 / 报文 / 分组）、按传输（广播式 / 点对点）。
- **因特网 = 分组交换**：存储转发、逐组独立选路、统计复用，突发数据远优于电路交换（数值对比放 N3）。
- 速率与带宽单位 `b/s`：前缀**十进制** 1 Kb/s=10³、1 Mb/s=10⁶、1 Gb/s=10⁹；**1 Byte=8 bit**；存储单位（KB/MB）常按 2 的幂（1 KB=1024 B）——换算先判语境。
- 吞吐量 = 实际通过率，≤ 带宽（标称值）。
- **时延四兄弟**：发送 = L/R；传播 = d/v；处理；排队。总时延 = 四者之和（题说忽略就不加）。
- **时延带宽积 = 传播时延 × 带宽**：这条链路「装满」时能容纳的比特数。
- RTT = 往返总时间；只算传播部分时 = 2 × 单向传播。
- 利用率 U → 时延 D = D₀/(1−U)：U 越接近 1 时延越爆炸（D₀ = 空闲时延）。

## 二、本课知识点（完整版）

### 2.1 定义与组成

- 定义关键句：计算机网络是**分布在不同地理位置**、具有**独立（自治）功能**的多台计算机及外部设备，通过**通信线路**互连，在网络操作系统、网络管理软件及**通信协议**的管理协调下，实现**资源共享与信息传递**的系统。
- 为什么必须「自治」：每台机器都能独立工作（不依赖服务器也能算），网络是把它们连起来协作，而不是主从关系。
- 组成的三种视角：

| 视角 | 内容 |
| --- | --- |
| 组成成分 | 硬件（主机 / 终端 / 线路 / 设备）+ 软件（系统 / 应用）+ 协议 |
| 工作方式 | 边缘部分（用户直接用：C/S、P2P）+ 核心部分（路由器组成的分组交换转发网） |
| 功能组成 | 数据通信（基础）+ 资源共享（核心）+ 分布式处理等 |

- 注意两对概念别混淆：**边缘 / 核心**按「谁在使用」划分；**资源子网（主机+终端）/ 通信子网（路由器+通信链路）**按「提供资源 / 搬运数据」划分。路由器属于核心部分，也属于通信子网。

### 2.2 功能（简答常考）

1. 数据通信（**最基本**的功能：把数据从一端传到另一端）
2. 资源共享（**最主要 / 核心目的**：硬件资源共享、软件资源共享、数据资源共享）
3. 分布式处理与并行计算
4. 负载均衡
5. 提高可靠性
6. 信息综合处理

> 记忆链：传（通信）→ 共（共享）→ 分（分布并行）→ 均（均衡）→ 靠（可靠）。
> 判读陷阱：题目问「最主要功能」答资源共享；问「最基本功能」答数据通信。

### 2.3 分类

| 分类维度 | 类型 |
| --- | --- |
| 分布范围 | 个域网 PAN < 局域网 LAN < 城域网 MAN < 广域网 WAN（因特网=最大的 WAN） |
| 使用者 | 公用网（如电信网）/ 专用网（如银行、铁路专网） |
| 拓扑结构 | 总线型 / 星型（中心故障全瘫）/ 环型 / 网状型（最可靠、最贵） |
| 交换技术 | 电路交换 / 报文交换 / 分组交换 |
| 传输技术 | 广播式（共享信道，一呼百应）/ 点对点（链路两端只连两个结点） |

### 2.4 性能指标（本课计算主力）

**① 速率（数据率 / 比特率）**：单位时间传输的比特数，单位 b/s（bps）。换算全用 10 的幂：K=10³，M=10⁶，G=10⁹，T=10¹²。⚠️ 与存储单位的 2 的幂（1 KB=1024 B）不同源，换算前先看题目给的是「速率」还是「文件字节数」。

**② 带宽**（数字信道）：信道的**最高数据率**，单位同速率。（模拟带宽单位 Hz 是另一概念，N3 展开。）

**③ 吞吐量**：单位时间**实际**通过的数据量（实测值），永远 ≤ 带宽。

**④ 时延四兄弟**（各自独立，别混）：

| 名称 | 公式 | 取决于 | 与什么无关 |
| --- | --- | --- | --- |
| 发送时延（传输时延） | 数据长度 L ÷ 发送速率 R | L、R | 距离、传播速度 |
| 传播时延 | 信道长度 d ÷ 传播速率 v | d、v（介质） | 数据长度、带宽 |
| 处理时延 | —（查表 / 分析等） | 结点处理能力 | 题说忽略则计 0 |
| 排队时延 | —（队列等待） | 拥塞程度 | 题说忽略则计 0 |

- 总时延 = 发送 + 传播 + 处理 + 排队（题目注明「忽略」哪几项，就只加剩下的）。
- 直观类比（收费站 + 高速公路）：**发送时延** = 车队全部通过收费口的时间（车数=数据量、放行速度=带宽）；**传播时延** = 第一辆车从入口开到出口的行驶时间（路长=链路长度、车速=电磁波速度）。两者一个发生在「上线前」，一个发生在「线路上」，互不依赖。

**⑤ 时延带宽积 = 传播时延 × 带宽**（单位 bit）：物理意义——某时刻链路上最多能「塞」多少比特，也叫「以比特为单位的链路长度」。

**⑥ 往返时延 RTT**：发送方发出数据到收到对方确认的**总**时间。题目说「往返传播时延」→ 2 × 单向传播；说完整 RTT → 可能还含处理 / 确认发送时间，按题意。

**⑦ 利用率**：信道利用率 U = 有数据通过的时间 ÷ 总观察时间；网络时延 D = D₀/(1−U)（D₀ 为网络空闲时延）。U=50% → D=2D₀；U=90% → D=10D₀；U→1 → D→∞（拥塞临界，这就是为什么网络不能「满载跑」）。

### 2.5 课堂例题（改过数字就是作业）

**例 1（发送主导）**：文件 8×10⁶ bit，带宽 10 Mb/s = 10⁷ bps，链路 500 km = 5×10⁵ m，传播速度 2×10⁸ m/s，忽略处理与排队。

```
send_delay = 8e6 / 1e7     = 0.8 s      (800 ms)
prop_delay = 5e5 / 2e8     = 0.0025 s   (2.5 ms)
total      = 0.8025 s
delay-bandwidth product    = 0.0025 × 1e7 = 25000 bit
```

**例 2（传播主导）**：同一链路，文件改成 8×10³ bit（≈1 KB）：

```
send_delay = 8e3 / 1e7 = 0.0008 s (0.8 ms) < prop 2.5 ms → 传播主导！
```

结论：谁主导**直接比两个数值大小**，不要凭「距离远不远 / 文件大不大」的感觉。

**例 3（单位陷阱）**：2 KB 文件 = 2 × 1024 × 8 = 16384 bit；以 1 Mb/s 发送 → 16384 ÷ 10⁶ ≈ 0.016384 s ≈ 16.4 ms。

**例 4（卫星链路）**：卫星高 3.6×10⁴ km → 单向传播 ≈ 3.6×10⁷ ÷ 3×10⁸ = 0.12 s → 往返传播 ≈ 0.24 s。卫星链路传播时延巨大：小文件也是传播主导（高频题眼）。

## 三、代码模板

`net_delay.c` —— 发送时延 / 传播时延 / 总时延 / 时延带宽积 / RTT 传播部分 计算器（全部英文输出）：

```c
/* net_delay.c — Lesson N1: transmission / propagation delay calculator
 * (408 Computer Networks, Chapter 1 performance metrics)
 *
 * Build & run (Windows, from this file's folder):
 *     gcc net_delay.c -o net_delay
 *     net_delay.exe
 *
 * Inputs (decimal numbers, convert units BEFORE typing):
 *     1) file size in bits      (e.g. 10^7 bit = 10000000)
 *     2) bandwidth in bps       (e.g. 100 Mb/s = 100000000)
 *     3) link length in meters  (e.g. 1000 km = 1000000)
 *     4) propagation speed in m/s (copper cable ≈ 200000000)
 *
 * Outputs are ASCII English on purpose (no Chinese in the terminal).
 */
#include <stdio.h>

int main(void)
{
    double bits, rate, dist, speed;

    printf("Enter file size (bit): ");
    if (scanf("%lf", &bits) != 1) { printf("bad input\n"); return 1; }
    printf("Enter bandwidth (bps): ");
    if (scanf("%lf", &rate) != 1) { printf("bad input\n"); return 1; }
    printf("Enter link length (m): ");
    if (scanf("%lf", &dist) != 1) { printf("bad input\n"); return 1; }
    printf("Enter propagation speed (m/s): ");
    if (scanf("%lf", &speed) != 1) { printf("bad input\n"); return 1; }

    double send  = bits / rate;      /* transmission delay = L / R     */
    double prop  = dist / speed;     /* propagation delay  = d / v     */
    double total = send + prop;      /* processing/queueing ignored    */
    double prod  = prop * rate;      /* delay-bandwidth product (bits) */
    double rttp  = 2.0 * prop;       /* RTT, propagation part only     */

    printf("file_size          = %.0f bit\n", bits);
    printf("bandwidth          = %.0f bps\n", rate);
    printf("send_delay         = %.9f s\n", send);
    printf("propagation_delay  = %.9f s\n", prop);
    printf("total_delay        = %.9f s\n", total);
    printf("delay_bandwidth_product = %.6f bit\n", prod);
    printf("rtt_propagation    = %.9f s\n", rttp);
    return 0;
}
```

主测试组期望输出（输入 10000000 / 100000000 / 1000000 / 200000000）：

```
file_size          = 10000000 bit
bandwidth          = 100000000 bps
send_delay         = 0.100000000 s
propagation_delay  = 0.005000000 s
total_delay        = 0.105000000 s
delay_bandwidth_product = 500000.000000 bit
rtt_propagation    = 0.010000000 s
```

> 用法铁律：单位换算（Byte→bit、km→m、Mb/s→bps）必须在**输入前**手算完成，程序只做公式；否则「程序对、口径错」判错。

| # | 坑 | 说明 | 正确做法 |

### H5（挑战 ★★★，选做）利用率爆炸

已知空闲时延 D₀ = 50 ms，公式 D = D₀/(1−U)。求 U = 0.5、0.9、0.99 时的 D，并写一句话说明「为什么网络实际运行不能让利用率无限接近 1」。

通关测试值：U=0.5 → **100 ms**；U=0.9 → **500 ms**；U=0.99 → **5000 ms（5 s）**。
