## 本课最容易丢分的地方

- **GBN ≤ 2ⁿ−1**，**SR ≤ 2ⁿ⁻¹** —— 减 1 的那个是 GBN。
- GBN **接收窗口恒为 1**、用**累积确认**；SR **收发窗口相同**、用**逐帧确认**、需要**接收缓存**。
- `a` 有两种定义（`RTT/T_d` 用 `1+a`；`RTT/(2T_d)` 用 `1+2a`）——**看题目给的定义式**，别背两套。
- 窗口滑动后**大小不变**；停等**也需要 1 位序号**。
