## 本课最容易丢分的地方

- **模 2 除法不是普通除法**：逐位 **XOR**，不借位。
- **余数位数固定为 r**（= 生成多项式位数 − 1），不够要**前面补 0**。
- 先补 r 个 0 再除；码字 = 数据位 ‖ 余数，总长 = 数据位数 + r。
- 奇偶校验**只能检出奇数个**错误。
