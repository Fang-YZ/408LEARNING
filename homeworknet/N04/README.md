## 本课最容易丢分的地方

- **中继器/集线器不隔离冲突域**；交换机隔离冲突域但**不隔离广播域**（VLAN 才切广播域）。
- **集线器共享带宽**（N 台平分），交换机**每口独占**——算"每设备带宽"时先判断介质类型。
- 光纤"抗电磁干扰"是因为**传的是光**；"保密性好"是因为**不向外辐射**——别说成"有屏蔽层"。
