# L1 复习笔记 — C 入门：main / 类型 / printf / scanf / 算术

> 课程：408 衔接 C/C++ 私教课 ｜ 日期：2026-09-09 ｜ 示例源码：lessons/L01_hello_types_io/examples/

## 一、30 秒速览

- C 程序入口是 `main`；每条语句以 `;` 结尾；`printf` 打印，`\n` 换行。
- 变量 = 类型 + 名字，使用前必须先「声明」，最好同时「初始化」。
- 整数类型：char / short / int / long / long long；小数：float / double（默认用 double）。
- Windows gcc 字节数：char 1 ｜ short 2 ｜ int 4 ｜ long 4 ｜ long long 8 ｜ float 4 ｜ double 8。
- 占位符：int → `%d`；double → printf 用 `%f`（可 `%.1f`），scanf 必须用 `%lf`；char → `%c`；long long → `%lld`。
- `scanf("...", &变量)` 必须带 `&`；printf 不带。
- 整数 / 整数 = 整数（截断）：`7/2 == 3`；想保留小数，至少一边是 double：`7/2.0 == 3.5`。
- `%` 取余：`7%2 == 1`；C99 向零截断：`-7/2 == -3`，`-7%2 == -1`。
- int 上限约 21 亿（2147483647），溢出会「回绕」成负数 → 大数用 long long。
- 代码风格公约：4 空格缩进、花括号独占一行且不省略、变量名 snake_case 有意义。

## 二、代码模板

**模板 1：main 骨架（每题的起点）**

```c
#include <stdio.h>

int main(void)
{
    // your code here

    return 0;
}
```

**模板 2：读入 → 计算 → 输出**

```c
#include <stdio.h>

int main(void)
{
    int total_seconds = 0;      // declare + initialize

    printf("Enter seconds: ");
    scanf("%d", &total_seconds);

    printf("total_seconds = %d\n", total_seconds);

    return 0;
}
```

**模板 3：格式化占位符速查**

| 需求 | 写法 | 示例输出 |
| --- | --- | --- |
| 整数 | `%d` | 42 |
| 保留 1 位小数 | `%.1f` | 37.0 |
| 保留 2 位小数 | `%.2f` | 37.00 |
| 两位数不足补 0 | `%02d` | 07 |
| 单个字符 | `%c` | A |
| long long | `%lld` | 4000000000 |
| scanf 读 double | `%lf` + `&x` | — |
| 输出 double | `%f`（配 `%.nf` 控小数位） | 3.14 |

**模板 4：查类型字节数**

```c
printf("int = %d bytes\n", (int)sizeof(int));
```

## 三、坑清单

| # | 坑 | 现象 | 正确写法 |
| --- | --- | --- | --- |
| 1 | scanf 忘记 `&` | 程序崩溃或值没读进来 | `scanf("%d", &x);` |
| 2 | scanf 读 double 却用 `%f` | 读到垃圾值 / 乱码数字 | `scanf("%lf", &x);`（printf 输出才用 `%f`） |
| 3 | 整数 / 整数 | 小数被截掉：`5/9 == 0`，平均分算出 0 | 至少一边写小数：`5.0/9`、`sum/3.0` |
| 4 | 负数除法的方向猜错 | 以为 -7/2 == -4 | C99 向零截断：`-7/2 == -3`，`-7%2 == -1` |
| 5 | int 溢出 | `2147483647 + 1` 变成负数 | 大数先想 long long |
| 6 | 变量不初始化就用 | 「垃圾值」，每次运行结果不一样 | 声明时给初值：`int x = 0;` |
| 7 | 拼写 / 大小写 / 丢分号 | 编译报错 | C 区分大小写；每条语句以 `;` 结尾 |
| 8 | printf 忘写 `\n` | 输出全挤一行，甚至运行结束才显示 | 每行输出结尾加 `\n` |
| 9 | 代码里写中文（字符串/注释） | Windows 控制台乱码 / 编译告警 | 代码、注释一律英文 ASCII |
| 10 | scanf 输入类型不匹配（如 `%d` 收到字母） | 后续读取全乱 | 本课约定输入合法；防御输入以后课再学 |
| 11 | MinGW 下 `%lld` 配 `-Wall -Wextra` 报 `unknown conversion type 'l'` | 工具链按 msvcrt 格式检查，不认 `%lld`（运行时其实正常；Linux gcc 无此问题） | 编译加 `-D__USE_MINGW_ANSI_STDIO=1`，或在 `#include <stdio.h>` 前写 `#define __USE_MINGW_ANSI_STDIO 1`（2026-09-09 已实测两者零警告） |

### HW1（必做 ★）类型尺寸报告 — hw1_sizes.c

- 用 printf + sizeof 输出 7 种类型各占几字节（顺序：char, short, int, long, long long, float, double）。
- 第一行打印 `Type Size Report`，最后一行打印 `End of Report`。
- 对齐随便（空白不计分），但类型名与数值必须逐行正确。
- 期望输出（Windows gcc；若你机器上 long 是 8，说明工具链不同，交作业时注明即可）：

```
Type Size Report
char        1
short       2
int         4
long        4
long long   8
float       4
double      8
End of Report
```

- 提示：一行写法 `printf("%-12s%d\n", "char", (int)sizeof(char));`（`-12` 左对齐占 12 宽，仅为了让表格整齐，数字对即可）。

### HW2（必做 ★★）秒 → 时:分:秒 — hw2_time.c

- 输入一个整数 `total_seconds`（保证 0 ≤ total_seconds ≤ 100000，本课先不要求校验输入）。
- 输出格式一行：`X:MM:SS`，分和秒必须两位、不足补 0（提示：`printf("%d:%02d:%02d\n", h, m, s);`）。
- 通关测试值（输入 → 期望输出，全部要跑）：

| 输入 | 期望输出 |
| --- | --- |
| 0 | 0:00:00 |
| 59 | 0:00:59 |
| 60 | 0:01:00 |
| 3600 | 1:00:00 |
| 3661 | 1:01:01 |
| 3725 | 1:02:05 |
| 100000 | 27:46:40 |

- 验算方法：3725 = 1×3600 + 2×60 + 5。中间量：h = total/3600；m = (total/60)%60；s = total%60。

### HW3（必做 ★★）华氏度 → 摄氏度 — hw3_celsius.c

- 输入一个 double `fahrenheit`（合法范围 [-100, 212]，保证合法，不用校验）。
- 换算公式：C = (F − 32) × 5 / 9。
- 输出一行，两位小数：`%.2f F -> %.2f C`。
- 通关测试值（输入 → 期望输出）：

| 输入 | 期望输出 |
| --- | --- |
| 32.0 | 32.00 F -> 0.00 C |
| 212.0 | 212.00 F -> 100.00 C |
| 98.6 | 98.60 F -> 37.00 C |
| -40.0 | -40.00 F -> -40.00 C |
| 0.0 | 0.00 F -> -17.78 C |
| -100.0 | -100.00 F -> -73.33 C |

- 特别要求：代码里**不允许**出现单独的 `5/9` 整数除法（会等于 0）；用 double 全程计算。

### HW4（挑战 ★★★）int 溢出现场 — hw4_overflow.c

- 输入两个 int：a、b（范围 -2147483647 ~ 2147483647），输出它们的和。
- 第一版用 int 保存和，跑一遍观察结果；然后把和改成 long long（提示：`(long long)a + b`）再跑。
- 通关测试值（对修正版）：

| 输入 | 期望输出 |
| --- | --- |
| 2000000000 2000000000 | 4000000000 |
| 2147483647 0 | 2147483647 |
| 2147483647 1 | 2147483648 |
| -2000000000 -2000000000 | -4000000000 |
| -1 1 | 0 |

## 参考：7 种基本类型（Windows gcc / MinGW-W64 实测）

| 类型 | 字节 | 大致范围 | 用途 |
| --- | --- | --- | --- |
| char | 1 | -128 ~ 127 | 单个字符 / 小整数 |
| short | 2 | -32768 ~ 32767 | 少见 |
| int | 4 | ±21 亿 | 默认整数，数据结构里存下标/计数 |
| long | 4（Windows）/ 8（Linux） | 同 int（Windows） | 注意：Windows 与 Linux 不一样！ |
| long long | 8 | 极大 | 防溢出时用 |
| float | 4 | 约 7 位有效数字 | 一般不用 |
| double | 8 | 约 15 位有效数字 | 默认小数，一律用它 |

> 408 教材与大多数 OJ 按 64 位 Linux 讲（那里 long 是 8 字节）。我们平时写代码就用 int / long long / double，把 long 当「陷阱」记住即可。
